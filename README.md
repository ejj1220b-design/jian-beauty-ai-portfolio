# 정지안 · 글로벌 뷰티 & AI 포트폴리오

독립 정적 웹사이트입니다. `index.html`, `portfolio.css`, `portfolio.js`와 이미지·영상 파일을 같은 위치에 두면 됩니다.

## 구성

- 대표 작업: 성과 분석·운영 시스템 → 소재 진단 → 일본 Qoo10 → 이전 TikTok 광고 개선
- 보조 AI 업무 도구: 광고비 정산 체커, 카피 라이브러리
- 콘텐츠 실험: 영어 쇼퍼블 라이브, 국내 뷰티 인스타그램, 해외 뷰티 숏폼, 먹스타그램, 블로그
- 경력·역량: 전체 광고 경력과 리터니티의 뷰티 이커머스 경력을 나눠 설명
- `archive.html`: 2026-10-21 확인한 GitHub `2026update`의 기존 포트폴리오를 보존한 페이지

## 국내 뷰티 인스타그램 자료 추가

`index.html`에서 `id="domestic-beauty"`를 찾습니다.

1. `reserved-grid`의 콘텐츠 01~03 자리에 대표 이미지 또는 영상을 넣습니다.
2. 각 콘텐츠에 제작 의도, 확인한 반응, 다음에 바꿀 점을 짧게 적습니다.
3. 실제 자료가 채워지면 `자료 준비 중` 표시를 바꿉니다.
4. 계정 주소가 정해지면 해당 카드에 실제 프로필 링크를 추가합니다.

실제 콘텐츠·핸들·조회수·팔로워 수는 미리 만들지 않았습니다. 이미지 확대는 기존 카드의 `data-zoom` 버튼 구조를 복사하면 사용할 수 있습니다.

## 자료 교체

- `desk-demo.png`, `desk-amazon-demo.png`: 가상 데이터 데모 화면
- `returnity-console-public.png`, `returnity-diagnosis-public.png`, `returnity-flow-public.png`: 공개용으로 편집된 업무 화면
- `qoo10-ranking.png`: 날짜·검색어·정렬 조건이 있는 공개 검색 화면
- `live-demo.mp4`, `live-poster.jpg`: 쇼퍼블 라이브 발췌 영상과 표지

업무 화면을 교체할 때 실제 광고비·계정 식별자·수수료·매출목표 같은 내부 정보를 확인하세요. 원본 ZIP, 거래 워크북, 내부 보고서는 포함하지 않았습니다.

## 내용 유지 기준

소재 37개·39페이지는 분석 및 제작 실행안입니다. 실제 소재 집행 성과로 바꾸지 않습니다. 기존 TikTok CPA 개선은 이전 병원 광고 사례입니다. Qoo10 캡처는 특정 날짜·검색 조건의 관찰입니다. 라이브 판매 경험은 사용자 진술에 따른 내용이며, 발췌 영상은 시연 장면입니다.

## 게시

이 폴더를 별도 GitHub 저장소의 루트에 올린 뒤 GitHub Pages의 게시 브랜치와 폴더를 설정합니다. `.nojekyll`이 포함되어 있습니다. 기존 저장소를 복제할 경우 원본 포트폴리오는 유지하고 새 저장소에서 게시합니다.
